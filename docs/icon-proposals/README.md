# VoiceRecorder iOS app icon proposals

Prepared on 2026-08-09 for visual approval. The owner approved variant 3 on 2026-08-09.

- `00-current.png`: original production baseline (cosmic atom/orbit).
- `00-original-cosmic-backup.png`: byte-for-byte backup of that original production icon.
- `01-record-wave.png`: record circle plus cyan waveform.
- `02-mic-arcs.png`: minimal microphone capsule with broadcast arcs.
- `03-ribbon-dot.png`: continuous waveform ribbon with a central red record dot.
- `04-meter-dot.png`: five-bar audio meter with a central orange record dot.

Approved selection: `03-ribbon-dot.png`. It communicates recording and audio directly, remains professional and readable at small sizes, and avoids the generic microphone treatment. It is installed in the iOS asset catalog as a 1024 x 1024 opaque PNG.

All four alternatives were generated with the built-in image generation tool as original, text-free, opaque-background iOS icon concepts. Source previews are 1254 x 1254 pixels; the approved concept was normalized to Apple's 1024 x 1024 source size without changing its design.
